System Architecture & Overview

Comprehensive technical documentation for the IoT Weather Monitoring Station developed at Government Polytechnic College Anantnag.

Project Overview

The GPCA Weather Station is an educational and functional Internet of Things (IoT) project engineered by Computer Science students at Government Polytechnic College Anantnag. It provides automated, real-time meteorological monitoring using connected sensors, edge microcontrollers, and a cloud-native backend pipeline.

This repository serves as the official project showcase and live monitoring client, demonstrating full-stack IoT capabilities from hardware serial communication to cloud database persistence and responsive web dashboards.

System Architecture

1. Edge Sensing Layer

ESP8266 microcontroller gathering raw telemetry from DHT11, rain, wind, and visibility sensors.

2. Transport Layer

Secure HTTP/REST transmission of structured JSON payloads over Wi-Fi network infrastructure.

3. Backend Pipeline

Flask (Python) server handling request validation, priority alert evaluation, and time-series persistence.

4. Presentation Layer

Responsive web client utilizing Chart.js for real-time visualization and historical trend analysis.

Hardware Specification

  • Microcontroller: ESP8266 Wi-Fi SoC
  • Temperature & Humidity: DHT11 Digital Sensor
  • Precipitation: Resistive/Digital Rain Detection Module
  • Wind Measurement: Custom Anemometer Pulse Counter (GPIO Interrupt)
  • Visibility Index: LDR Photocell Ambient Light Sensor
