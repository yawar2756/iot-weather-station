🌦 About This Project

I built this IoT Weather Station to track real-time environmental conditions using ESP8266/ESP32. The main goal was to create a simple and low-cost system that can monitor weather without depending on expensive setups.

The system collects live data like temperature, humidity, rainfall, wind speed, and visibility, and sends it to an online dashboard for monitoring.

💡 This system updates data every few seconds and shows real-time changes directly on the dashboard.

⚙️ How It Works

Sensors are connected to the ESP module, which reads data at regular intervals. The data is converted into JSON format and sent to a Flask backend over WiFi.

The backend stores this data in a PostgreSQL database and sends it to the dashboard for live visualization.

🧪 Sensors & Hardware

The system uses a DHT11 sensor for temperature and humidity, along with rain and wind sensors. Some sensors like visibility are optional, and the system automatically handles cases when they are not connected.

🧠 Backend Logic

The backend is built using Flask and manages all incoming sensor data. It stores data in a database, calculates statistics, and generates alerts like heat warnings, storm alerts, and rain notifications.

It also detects whether the device is online or offline based on the latest data received.

⚠️ Challenges Faced

  • Unstable WiFi causing delayed updates
  • Sensor accuracy and calibration issues
  • Server downtime during deployment
  • Handling missing or disconnected sensors
