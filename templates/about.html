🌦 About IoT Weather Station Project

The IoT Weather Station is a smart environmental monitoring system developed using ESP8266 and ESP32 microcontrollers. It collects real-time weather data such as temperature, humidity, rainfall, wind speed, wind direction, and visibility. The system sends this data to a web-based dashboard for monitoring and analysis.

⚙️ System Overview

This project combines sensors, microcontrollers, and cloud technology to create an efficient weather monitoring solution. It is designed to be low-cost, scalable, and useful for agriculture, education, research, and smart city applications.

🌡 Sensors Used

The system uses temperature and humidity sensors like DHT11 or DHT22, rain detection sensors, wind speed sensors, wind direction modules, and visibility sensors. These sensors continuously collect environmental data and send it to the microcontroller.

📡 Working Process

The ESP8266 or ESP32 reads sensor data at regular intervals and converts it into structured JSON format. The data is transmitted through WiFi to a backend server using HTTP requests. The server stores and processes the data for visualization.

🗄 Backend and Dashboard

The backend is built using Flask and stores data in a database. The dashboard displays real-time data using charts and analytics. It also provides alerts such as heat warnings, storm alerts, and rain notifications.

🚀 Applications

  • Agriculture and crop monitoring
  • Smart city environmental systems
  • Weather research and analysis
  • Disaster management planning
