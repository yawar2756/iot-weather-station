📌 Overview

This system collects real-time environmental data using ESP8266/ESP32, processes it through a backend system, and displays it on a live dashboard for continuous monitoring.

💡 Updates every few seconds with live sensor data

⚙️ How It Works

  • 📡 Sensors collect environmental data
  • 📶 ESP sends data via WiFi
  • 🧠 Flask backend processes and stores data
  • 📊 Dashboard displays real-time updates

🧪 Sensors & Hardware

  • 🌡 DHT11 sensor for temperature & humidity
  • 🌧 Rain sensor for rainfall detection
  • 🌬 Wind sensor for wind speed
  • 👁 Optional visibility sensor support

🧠 Backend Logic

  • 🧠 Flask backend processes incoming data
  • 💾 Stores data in PostgreSQL database
  • 📊 Generates analytics and statistics
  • ⚠️ Triggers alerts (rain, heat, etc.)
  • 📡 Detects device online/offline status

⚠️ Challenges Faced

  • Unstable WiFi connections
  • Sensor calibration issues
  • Server downtime
  • Handling missing data

⚠️ Limitations & Drawbacks

  • Dependent on sensor stability
  • Requires continuous internet
  • Data gaps during downtime
  • Limited accuracy of DHT11
  • Needs stable power supply
  • Basic API security

🚀 Applications

  • Agriculture monitoring
  • Local weather tracking
  • Research & education
  • Smart environment systems

🛠 Tech Stack

  • Hardware: ESP8266 / ESP32
  • Frontend: HTML, CSS, JS, Chart.js
  • Backend: Flask (Python)
  • Database: PostgreSQL
  • Deployment: Render

🔮 Future Improvements

  • Air quality & UV sensors
  • Mobile app integration
  • AI-based predictions

Built as part of an IoT-based smart monitoring system project.
