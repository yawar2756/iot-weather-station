🌦 GPCA Weather Station

Real-time IoT weather monitoring system built with ESP8266 & ESP32. Live data visualization, intelligent alerts, and seamless dashboard experience.

The GPCA Weather Station is an IoT-based smart weather monitoring system developed by students of Government Polytechnic College Anantnag (GPCA). The project provides real-time environmental monitoring using ESP8266 technology.
