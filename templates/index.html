📌 Overview

This system collects real-time environmental data using ESP8266/ESP32 microcontrollers, processes it through a Flask backend, and displays live updates on a responsive dashboard for continuous monitoring and analysis.

⚙️ How It Works

  • Sensors collect environmental data continuously
  • ESP microcontroller sends data via WiFi
  • Flask backend processes and stores data
  • Dashboard displays real-time updates

🧪 Sensors & Hardware

  • DHT11 sensor for temperature & humidity
  • Rain sensor for rainfall detection
  • Wind sensor for wind speed monitoring
  • Optional visibility sensor support

🧠 Backend Logic

  • Flask backend processes incoming JSON data
  • PostgreSQL database stores time-series data
  • Real-time analytics and statistics generation
  • Smart alerts for rain, extreme heat, etc.
  • Device online/offline status detection

⚠️ Challenges Faced

  • Unstable WiFi connections in remote areas
  • Sensor calibration and drift issues
  • Server downtime and data synchronization
  • Handling missing data gracefully

⚠️ Current Limitations

  • Dependent on sensor hardware stability
  • Requires continuous internet connectivity
  • Data gaps during network/server downtime
  • Limited accuracy of DHT11 sensor
  • Needs stable power supply

🚀 Real-World Applications

  • Precision agriculture monitoring
  • Local weather tracking stations
  • Research & educational projects
  • Smart city environmental systems

🛠 Complete Tech Stack

  • Hardware: ESP8266 / ESP32 microcontrollers
  • Frontend: HTML5, CSS3, Vanilla JS, Chart.js
  • Backend: Flask (Python) API server
  • Database: PostgreSQL time-series database
  • Deployment: Render cloud platform
