IoT Weather Station using ESP8266

This project is a real-time IoT-based weather monitoring system that collects environmental data using sensors and displays it on a live web dashboard.

🚀 Open Live Dashboard

📊 Features

  • Real-time temperature and humidity monitoring
  • Wind speed and wind direction tracking
  • Rain detection system
  • Visibility monitoring
  • Cloud-based dashboard

⚙️ How It Works

Sensors collect environmental data which is processed by ESP8266 and sent to a Flask server via API. The data is stored and displayed on a live dashboard.

🌍 Applications

  • Agriculture monitoring
  • Smart cities
  • Weather research
  • Disaster management
