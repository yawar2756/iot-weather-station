🌦 IoT Weather Station using ESP8266 & ESP32

This IoT Weather Station is a real-time smart monitoring system using ESP8266 and ESP32 that tracks temperature, humidity, wind speed, rainfall, and visibility with a live cloud dashboard.

📊 Features

  • Real-time temperature and humidity monitoring
  • Wind speed and wind direction tracking
  • Rain detection system
  • Visibility monitoring
  • Cloud-based live dashboard
  • Automatic weather alert system

⚙️ How It Works

Sensors collect environmental data which is processed by ESP8266/ESP32 microcontroller. The data is sent via WiFi to a Flask-based backend API, stored in a database, and displayed on a real-time dashboard with charts and analytics.

🌍 Applications

  • Agriculture and crop monitoring
  • Smart cities and climate tracking
  • Weather research and analysis
  • Disaster management systems
