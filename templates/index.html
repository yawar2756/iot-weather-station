🌦 IoT Weather Station using ESP8266 & ESP32

This IoT Weather Station project is a real-time smart weather monitoring system. It tracks temperature, humidity, wind speed, rainfall, and visibility using sensors and displays live data on an interactive dashboard.

🚀 Open Live Dashboard

Learn more about how the system works on our detailed project explanation page.

📊 Features

  • Real-time temperature and humidity monitoring
  • Wind speed and wind direction tracking
  • Rain detection system
  • Visibility monitoring
  • Cloud-based live dashboard
  • Automatic weather alert system

🌐 Live Weather Dashboard

View real-time weather data including temperature, humidity, wind, and rainfall using our IoT system powered by ESP8266 or ESP32.

🌍 Applications

  • Agriculture and crop monitoring
  • Smart cities and climate tracking
  • Weather research and analysis
  • Disaster management systems
