🌦 GPCA Weather Station

A real-time IoT weather monitoring system built using ESP8266 & ESP32. Track live temperature, humidity, wind, and rainfall directly from sensors to a web dashboard.

🚀 View Live Dashboard
📘 How It Works
⚡ Live data updates every few seconds with automatic alerts and device status tracking.

📊 Features

🌡 Real-time temperature & humidity
🌧 Rain detection system
🌬 Wind speed tracking
📡 Live cloud dashboard
⚠ Automatic weather alerts
📈 Data analytics & trends

⚙️ System Flow

Sensors collect environmental data
ESP8266/ESP32 processes readings
Data sent via WiFi (JSON)
Flask backend stores & processes
Dashboard displays live updates

🌍 Applications

🌾 Agriculture monitoring
🏙 Smart city systems
📊 Weather analysis
🚨 Disaster monitoring
